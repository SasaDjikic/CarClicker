# CarClicker

A fun and addictive car clicker game built with Unity.

## About

CarClicker is an incremental/idle game where players click to earn money and upgrade their car collection.

## Project Setup

This is a Unity project. To get started:

1. Install [Unity Hub](https://unity.com/download)
2. Clone this repository
3. Open the project in Unity
4. Start developing!

## Requirements

- Unity 2022 LTS or later
- Git
